# Week 3 — Requirements

## Functional requirements
1. Student registration.
2. Student login.
3. Grade selection.
4. Preferred-language selection.
5. Browse learning content by grade/subject/language.
6. Open a lesson.
7. Browse quizzes.
8. Attempt and submit a quiz.
9. Store quiz responses/results for later analysis/recommendation.
10. Design support for chatbot interaction and teacher dashboard.

## Non-functional requirements
- Modular React/FastAPI/MongoDB architecture.
- Readable and maintainable code.
- API-based frontend/backend communication.
- Persistent database storage for project data.
- Environment-based configuration for secrets.
- Responsive basic student UI.

## Scope
This implementation stops at Week 5. NLP preprocessing, DistilBERT embeddings and intent detection are intentionally deferred to later weeks.
