# Notes on the Week 6 dependencies:
#
# spacy 3.8.16+ ships prebuilt cp314 wheels (including blis). Older versions
# try to compile blis from source on Python 3.14, which needs Visual Studio
# build tools on Windows.
#
# torch 2.9.0 was the first release with Python 3.14 wheels. CUDA wheels for
# 3.14 do not exist yet, so this installs the CPU build. That is fine - this
# pipeline is inference-only on short text and does not need a GPU.
#
# On Python 3.12 or earlier, plain `pip install torch` on Linux pulls the CUDA
# build (~2.5 GB). For a CPU-only machine use:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# After installing, fetch the spaCy model and NLTK corpora:
#   python -m backend.nlp.setup_nlp
